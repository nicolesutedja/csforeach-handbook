# CSforeach

Handoff docs for CSforeach presidents, passed down year to year. Built with [Just the Docs](https://just-the-docs.github.io/just-the-docs/) and hosted on GitHub Pages.

## Editing
- Every page is a Markdown file in this repo. Edit and push to `main`; the site rebuilds automatically.
- Preview locally: `bundle install` then `bundle exec jekyll serve` (opens at `localhost:4000`).
- **Never commit passwords or private keys.** Use the club password manager.
